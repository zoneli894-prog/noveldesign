组件协作、Store 变更与数据流

组件协作流程

用户右键点击 TreeNode
1. TreeNode @contextmenu → 打开 ContextMenu（x, y 坐标）
2. ContextMenu 显示菜单项
用户点击"新建子词条"
3. ContextMenu 关闭 → TreeNode mode = 'creating'
4. TreeNode 内显示类型下拉 + 标题输入
5. 用户输入标题 → Enter → emit createChild
6. LeftSidebar 接收事件 → novelStore.addDoc()
7. TreeNode 自动展开 + 导航到新词条
用户点击"删除"
8. ContextMenu 关闭 → emit delete → CenterPanel
9. CenterPanel 显示 ConfirmDialog
10. 确认 → novelStore.deleteDoc()
