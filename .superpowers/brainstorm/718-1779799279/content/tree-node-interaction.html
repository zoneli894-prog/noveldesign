TreeNode 状态机

idle → creating (右键菜单"新建子词条")
idle → creating-sibling (右键菜单"新建同级词条")
idle → renaming (右键菜单"重命名")
creating → idle (Enter 提交 / Esc 取消)
creating-sibling → idle (Enter 提交 / Esc 取消)
renaming → idle (Enter 提交 / Esc 取消)

新建子词条 vs 新建同级词条

新建子词条
在当前节点下方插入表单
创建后成为当前节点的 child
自动展开当前节点
新建同级词条
在当前节点下方插入表单
创建后成为当前节点的 sibling
插入到当前节点之后
