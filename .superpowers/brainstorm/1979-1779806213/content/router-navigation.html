路由与导航变更

两级路由结构 + 项目切换

路由结构

/ → 重定向到第一个项目首页
/project/:pid → ProjectHome.vue（项目首页）
/project/:pid/doc/:docId → App.vue（现有三栏布局）

导航流程

打开应用
1. 检查 localStorage → 有项目数据？
→ 是：重定向到第一个项目首页
→ 否：显示空状态 + 创建引导
从项目首页进入项目
2. 点击项目卡片 → push(/project/:pid/doc/第一个词条)
从项目内返回
3. 左栏顶部项目名 → click → push(/project/:pid)
4. 面包屑第一级 → click → push(/project/:pid)
